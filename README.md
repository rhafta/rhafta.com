# rhafta.com

작은 3D 방으로 만든 개인 웹사이트. 실제 방(3.3m × 3.3m + 테라스) 구조를 옮긴
아이소메트릭 방에서 내 캐릭터가 데스크 셋업 앞에 앉아 코딩하고 있고, 방문자의
실제 시간에 따라 방의 낮/밤이 바뀝니다.

## 구현된 것

- **3D 방** — Three.js로 절차 생성한 로우폴리 방 (외부 모델 파일 없음). 실제 방
  구조 기반: 뒷벽에 방문·책장, 오른쪽 벽을 따라 침대, 침대 발치의 오픈 옷장,
  왼쪽 벽에 책상, 전면에 슬라이딩 유리문 + 통유리 발코니 테라스(카페 테이블·의자)
- **오픈 옷장** — 문 없이 내부가 보이는 형태: 행거에 걸린 옷들 + 선반의 개어놓은
  옷 + 하단 서랍
- **개발자 데스크 셋업** — 화이트 모션데스크 + 가로 메인 모니터 + 세로 서브
  모니터 + 스탠드 위 노트북. 화면들은 캔버스 텍스처로 그린 IDE/터미널이 표시됨.
  키보드·마우스·데스크매트·폰 스탠드·헤드폰 스탠드·머그(김 애니메이션)
- **LED 백라이트** — 모니터 뒤 벽면 LED 스트립. 밤에는 시안 글로우가 데스크
  존을 지배하는 조명이 됨 (천천히 숨쉬는 애니메이션)
- **캐릭터** — 책상 앞에서 타이핑하는 사람 비율 캐릭터 (숨쉬기 + 타이핑 모션)
- **개발자 디테일** — 프로그래밍 책이 꽂힌 책장, 러버덕 2마리(책상·책장),
  GitHub 잔디 액자, 터미널 아트 액자, 책상 밑 RGB PC 타워
- **낮/밤 동기화** — 방문자의 로컬 시간 기준. 06–08시 새벽, 18–20시 노을 구간은
  부드럽게 전환. 밤에는 LED 스트립이 방의 무드 조명이 됨
- **렌더링 품질** — N8AO(SSAO)로 가구 접촉 음영, UnrealBloom으로 발광체 글로우,
  절차적 우드그레인/벽 그라데이션/패브릭 텍스처, 환경맵(IBL), ACES 톤매핑
- 마우스 드래그 시점 회전, 낮/밤 토글 (`?mode=day|night`)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 빌드
npm run preview  # 빌드 결과 미리보기
```

## 구조

```
src/
  main.js              # 렌더러, 카메라, 조명, 루프, UI
  style.css            # 오버레이 UI (이름, 시계, 토글)
  scene/
    palette.js         # 색상 팔레트 — 감성 튜닝은 대부분 여기서
    room.js            # 방 지오메트리 (벽/문/테라스/책상 셋업/침대/옷장 등)
    character.js       # 캐릭터 + 타이핑 애니메이션
    daynight.js        # 시간 → nightness(0~1) 매핑, 조명/발광 제어
```

좌표계: 0.5m = 1 유닛. 방 바닥은 x, z ∈ [-3.3, 3.3], 벽은 뒤(-z)와 왼쪽(-x),
테라스는 +z 바깥. 디버그: `?focus=char` (+`&az=<라디안>`)으로 캐릭터 확대.
