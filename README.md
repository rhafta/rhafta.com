# rhafta.com

작은 3D 방으로 만든 개인 웹사이트. lofi haven / Virtual Cottage 감성의 아이소메트릭 방에서
내 캐릭터가 책상에 앉아 컴퓨터를 하고 있고, 방문자의 실제 시간에 따라 방의 낮/밤이 바뀝니다.

## 구현된 것 (v1)

- **3D 방** — Three.js로 절차 생성한 로우폴리 방 (외부 모델 파일 없음)
- **캐릭터** — 책상 앞에서 타이핑하는 애니메이션 (숨쉬기 + 타이핑 모션)
- **낮/밤 동기화** — 방문자의 로컬 시간 기준. 06–08시 새벽, 18–20시 노을 구간은 부드럽게 전환
- **무드등** — 밤이 되면 플로어 램프가 은은한 플리커와 함께 켜짐
- 창문 채광, 모니터 글로우, 머그컵 김, 마우스 드래그로 시점 회전 (제한된 각도)
- 좌측 하단 버튼으로 낮/밤 미리보기 (`?mode=day` / `?mode=night` URL로도 가능)

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 에 정적 빌드
npm run preview  # 빌드 결과 미리보기
```

## 구조

```
src/
  main.js              # 렌더러, 카메라, 조명, 루프, UI
  style.css            # 오버레이 UI (이름, 시계, 토글)
  scene/
    palette.js         # 색상 팔레트 — 감성 튜닝은 대부분 여기서
    room.js            # 방 지오메트리 (바닥, 벽, 창문, 가구, 램프)
    character.js       # 캐릭터 + 타이핑 애니메이션
    daynight.js        # 시간 → nightness(0~1) 매핑, 조명/발광 제어
```

방 배치를 실제 방 구조에 맞게 바꾸려면 `room.js`의 각 build 함수 좌표만 수정하면 됩니다.
바닥은 x ∈ [-5, 5], z ∈ [-4, 4], 벽은 뒤(-z)와 왼쪽(-x)에 있습니다.
